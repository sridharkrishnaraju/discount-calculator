# Discount & Percentage Calculator

A discount and percentage calculator: enter the original price and a discount percentage to get the final price and how much you save. Zero dependencies — works in plain HTML, React, Vue, Svelte or Astro.

**▶ [Live demo](https://sgbp.tech/tools/discount-calculator)**

```html
<script src="discount-calculator.js"></script>
<discount-calculator></discount-calculator>
```

## What it does

The maths is simple but easy to fumble at a counter: the amount saved is price × percent ÷ 100, and the final price is the rest. This tool does both instantly and formats the result, so 20% off $100 shows $80 to pay and $20 saved.

## Install

```bash
npm install @sgbp/discount-calculator
```

or copy `discount-calculator.js` into your project.
