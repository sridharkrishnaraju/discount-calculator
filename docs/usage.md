# Usage & API

It is a standard custom element, so it works with no wrapper in plain HTML, React, Vue, Svelte and Astro.

## Plain HTML

```html
<script src="discount-calculator.js"></script>
<discount-calculator></discount-calculator>
```

## React

```jsx
import "@sgbp/discount-calculator";
export default function Page() { return <discount-calculator />; }
```

## Vue

```vue
<script setup>
import "@sgbp/discount-calculator";
</script>

<template>
  <discount-calculator />
</template>
```
